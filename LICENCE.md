## 🧩 About

**Silkroad Online Companion** is a curated list of Silkroad Online open-source tools:

- **Overlays** — on-screen helpers, layout notes, route viewer, position tracker
- **Quality-of-Life Helpers** — inventory catalog, skill planner, overlay notes
- **Research Notes** — trade route layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 World Helpers
- Route Viewer — study trade routes from any checkpoint
- Position Tracker — visualize character position on the map
- Run Notes — record and review travel routes
- Movement Speed — adjust travel playback for study (0.1x to 5x)

### 🎒 Catalog & Inventory
- Item Catalog — browse items, gear, and consumables
- Custom Loadout Notes — organize character builds
- Inventory Overlay — improved inventory visibility

### 🏋️ Practice Layout
- Route Mode Notes — segment study on any map
- Camera Control — manually adjust camera mid-route
- Skill Buffer Notes — chain complex maneuvers in study mode
